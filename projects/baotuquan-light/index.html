把宿舍楼下的取水、洗澡、洗衣，收进同一个 App。

为什么做这个

这三个功能原本散在三个不同的 App 里：

  • 取水 —— 「慧生活798」
  • 洗澡 —— 「胖乖生活」
  • 洗衣 —— 支付宝里的「智慧笑联」小程序

每次用都得先想「这个该开哪个」，洗澡前还要为了刷开浴室先去登录取水。于是就有了这个 App： 三个服务收进一个界面，各自独立登录、并列可用，互不影响。

功能

  • 设备记忆与整理

    用过的设备自动记住，支持备注、按楼分组、置顶，也能长按拖动排序。

  • 实时占用水位

    洗澡页自动拉取本楼全部机器，按楼层分组标出空闲 / 使用中，不用站在门口一台台试。

  • 扫码添加设备

    扫机器上的二维码即可入库；也能直接从已拉取到的设备名单里挑。

  • 桌面小组件

    深色 / 浅色 / 柔光玻璃三种样式，点一下直达对应服务。

  • 深色模式

    跟随系统 / 始终浅色 / 始终深色三选一，切换立即生效。

  • 自动检查更新

    启动时自动查新版本，也能在设置里手动检查，直接在应用内下载安装。

怎么做的

整个项目没有用 Gradle，也没有用 Android Studio —— 全部靠命令行工具链直接构建：

aapt2 compile  →  aapt2 link（生成 R.java）  →  javac
   →  d8 转 dex  →  把 classes.dex 装进 APK  →  zipalign  →  apksigner

唯一的第三方依赖是 ZXing（二维码解码，Apache-2.0）。界面全部用 Android 原生控件手写， 没有任何 UI 框架，所以安装包只有 419 KB。

做法上是照着功能自己写：观察原有 App 的交互流程和接口协议，写清规格，再从零实现。 不搬第三方的 smali / 资源，也不绕过任何签名或授权校验。

下载

直接安装：下载最新 APK（419 KB）。 第一次安装时安卓会拦一下，弹出「未知来源」时选允许即可。

升级：不要卸载重装 —— 卸载会清掉已记住的设备和登录状态。App 内会自动提示新版本， 也可以直接覆盖安装。
